# Step 6: 边界分析（产出风险目录）

## 目标

自题面系统分析边界条件与常见错法，**产出风险目录**（含难度阈值列），供标程验证和测试数据设计引用。

⚠️ 本步骤在 Phase 2 与 `03-gesp.md`、`04-problem.md` **并行执行**，仅依赖题面内容。

## ⚠️ 核心原则

```
边界分析 ≠ 全部测
风险目录列所有潜在风险 → 按难度等级筛选 → 只有当前难度允许的风险才落地为测试点
```

**过度严苛的数据等于偷偷改了题目难度。** IRON 级别的求和题不需要测 `long long` 溢出。

---

## 第一步：约束枚举

自题面数据范围，**穷举**所有边界值及组合。

⚠️ **不仅要枚举输入约束，还要枚举输出约束！**

### 枚举模板

| 约束变量 | 下界 | 上界 | 特殊值 | 退化情况 |
|---------|------|------|--------|---------|
| N | min(N) | max(N) | N=1, N=2 | 空集/单元素 |
| a_i | min(a_i) | max(a_i) | 0, -1, 极值 | 全相同/已排序/逆序 |
| M | min(M) | max(M) | M=0, M=1 | 无操作/单操作 |
| 输出 | 声明下界 | 声明上界 | — | 答案为0/为上界 |

### 枚举要点

1. **每个约束变量都要考虑最小值和最大值**
2. **约束变量之间的组合**：N=max 且 a_i 全取极值
3. **退化情况**：N=1（只有一元素）、N=0（空集，若允许）、所有元素相同
4. **输入形态**：已排序、逆序、锯齿形、全 0、全负
5. **输出退化**：答案为 0、答案为负数、答案需取模且为 0
6. ⚠️ **输出端约束**：题面声明的输出上界（如 $E \\le 2.1 \\times 10^9$）、输出行数、精度要求——这些是**必检项**，不是可选

### 示例

**题：给定 N 个整数，求其中大于 K 的个数。**（1 ≤ N ≤ 10^5, 1 ≤ a_i ≤ 10^9, 1 ≤ K ≤ 10^9）

| 约束变量 | 边界 |
|---------|------|
| N | N=1, N=10^5 |
| a_i | a_i=1, a_i=10^9, a_i=K, a_i=K+1 |
| 组合 | N=1 且 a_i < K（答案=0）; N=10^5 且全 a_i > K（答案=N）|
| 退化 | 全部 a_i = K（答案=0）; 全部 a_i = K+1（答案=N）|
| 输出 | 答案必在 [0, N] 范围内（由题意可知） |

## 第二步：错解分析

针对**本题**分析可能的错误解法，不是泛泛的通用错法。

### 分析框架

对每种可能的错误解法，回答三个问题：

1. **这个错误解法是什么？**（具体的错误思路）
2. **什么数据能让它出错？**（触发条件）
3. **这道题的难度是否需要卡这个错法？**（难度判断）

### 常见错法分类（参考，非穷举）

| 错法类型 | 说明 | 典型难度阈值 |
|---------|------|-------------|
| int 溢出 | 用 int 而非 long long | SILVER+ |
| 边界漏判 | 未处理 N=1、空集等 | BRONZE+ |
| 精度误差 | float 代替 double、浮点比较 | SILVER+ |
| 错贪心 | 贪心策略不正确 | GOLD+ |
| 暴力超时 | O(n²) 替代 O(n log n) | SILVER+ |
| 漏判特殊情况 | 如图不连通、答案为 0 | SILVER+ |
| 模数陷阱 | 负数取模、未取模 | GOLD+ |
| 数组越界 | 下标从 0/1 混用 | BRONZE+ |

### 示例

**题：给定 N 个整数，求其中大于 K 的个数。**

| 错法 | 触发数据 | 难度阈值 |
|------|---------|---------|
| 用 int 累加计数（N=10^5 时不会溢出，不需要） | — | 不适用 |
| 未处理"全部 ≤ K"（答案=0） | a_i 全 ≤ K | BRONZE |
| 漏掉 a_i == K 的判断（> 还是 ≥？） | a_i = K 存在 | BRONZE |
| 读取时漏掉换行/空格 | 多行输入 | IRON |

## 第三步：产出风险目录

将约束枚举 + 错解分析汇总为**风险目录**，写入 `{WORK_DIR}/boundary.md`。

### 风险目录格式

```markdown
# 边界风险目录：{slug}

## 基本信息
- 题目：{title}
- 初评难度：{difficulty}
- 数据范围：N ∈ [{min}, {max}], a_i ∈ [{min}, {max}], ...

## 风险列表

| # | 风险描述 | 触发条件 | 针对错法 | 最低难度 | 当前题是否需测 |
|---|---------|---------|---------|---------|-------------|
| 1 | 答案为 0 | 全部 a_i ≤ K | 漏判"无满足" | BRONZE | ✅ |
| 2 | int 溢出 | 两近 2³¹-1 大数相加 | int 替 long long | SILVER | ❌ |
| 3 | a_i == K 边界 | 存在等于 K 的元素 | > 与 ≥ 混淆 | BRONZE | ✅ |
| 4 | N=1 退化 | 只有一个元素 | 循环边界错 | BRONZE | ✅ |
| 5 | ... | ... | ... | ... | ... |

## 选定测试边界（当前难度 {difficulty} 允许的风险）

- #1：答案为 0 的情况 → 生成 1 组
- #3：a_i == K 的情况 → 生成 1 组
- #4：N=1 的情况 → 生成 1 组
```

### "最低难度"列说明

- 标注该风险**从哪个难度级别开始值得测试**
- 低于该难度时，该风险不落地为测试点
- 参考映射：

| 最低难度 | 含义 |
|---------|------|
| IRON | 基本功，几乎所有题都应测 |
| BRONZE | 基本边界，入门以上应测 |
| SILVER | 需要一定意识才会注意的坑 |
| GOLD | 需要算法功底才能避开的坑 |
| PLATINUM+ | 高级陷阱，只有难题才需卡 |

### "当前题是否需测"列

- 取决于**当前题的初评难度 ≥ 最低难度**
- 初评难度为 BRONZE → IRON 和 BRONZE 级别的风险标 ✅，SILVER+ 标 ❌
- ⚠️ **终评难度变化时需重新筛选**（在 `07-std.md` 终评后更新）

---

产出 `{WORK_DIR}/boundary.md`，包含完整风险目录和选定测试边界。
