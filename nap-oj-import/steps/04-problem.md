# Step 4: 生题面

## 目标

生中文题面 `{WORK_DIR}/problem.md`。

## 铁律：仅译不编

1. 仅译，保原构
2. 禁 AI 内心戏：禁分析、推理、计算过程
3. 样例释：仅译原题释
4. **禁改样例**：样例输入/输出必原封不动复，不增删改任一字
5. **留图片链**：题面中图片链接（如 `![](url)` 或 `<img>` 标签）必原样留，不删不替
6. **留示意**：题面原有示意图、表格、公式等必完整留

## 标题格式

`# {slug} {title}`

例：
- `# P1057 做题`
- `# ABC453A 移除前导o(Trimo)`

## 题面格式

```markdown
# {slug} {title}

## 题目描述

[中文翻译]

## 输入格式

...

## 输出格式

...

## 输入输出样例 #1

### 输入 #1

```
...
```

### 输出 #1

```
...
```

## 说明/提示

...
```

### 格式要点

1. **标题行**：`# {slug} {title}`，slug 在前，title 在后
2. **节标题**：全部用 `##`（H2），不用 `####`（H4）
3. **样例**：用 `## 输入输出样例 #1` 合并节，子节用 `### 输入 #1` / `### 输出 #1`
4. **提示**：用 `## 说明/提示`，不用 `#### 数据范围`
5. **无外层包装**：不加 `<div class="water">` 或 `</div>`
6. **无知识点节**：不写"知识点与难度"节，难度和标签在 problem.json 中

## 多样例格式

若有多个样例：

```markdown
## 输入输出样例 #1

### 输入 #1

```
...
```

### 输出 #1

```
...
```

## 输入输出样例 #2

### 输入 #2

```
...
```

### 输出 #2

```
...
```
```

## AVOID

- ⚠️ **禁在 problem.md 中保留时间限制/内存限制**：题面首行的 `时间限制: X.XXs | 内存限制: XXX.XXMB` 仅用于提取配置，不写入 problem.md

## 更名工作目录（要务！）

生题面后，**将 slug 加入工作目录名**：

```bash
mv {WORK_DIR} {WORK_DIR}_{slug}
# {WORK_DIR} = {WORK_DIR}_{slug}
```

> **注**：若 slug 为 null（原创题），径用标题简写：
> ```bash
> mv {WORK_DIR} work_{标题简写}
> # {WORK_DIR} = work_{标题简写}
> ```
