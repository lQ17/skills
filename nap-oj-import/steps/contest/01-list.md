# Contest Step 1: 取赛题表

## 目标

访比赛任务列表页，析题信息，创题面汇总文件。

## 步骤

1. WebFetch 访比赛任务列表页
2. 解析题表：题号、标题、时限、内存
3. 创题面汇总文件：`{contest_id}.md`
4. 写入始标签
5. 报用户："现 N 道题，始逐题译..."

## 获取方式

用 WebFetch 访问 URL，提取题目列表信息：

```
WebFetch(url, "提取所有题目的题号、标题、链接")
```

**WebFetch 失败时**：请用户手动复制题目列表粘贴。

## 题面汇总文件格

```markdown
# {比赛名}

---

（后续题逐题追加写入）
```
