# Step 3: 定难度与标签（初评）

## 目标

据题面信息，做**初评**：四维评分 → 难度等级 + 知识点标签。

⚠️ 初评结果写入 problem.json 供参考，**终评在 step 6 标程写完后进行**，以终评为准。

---

## 第一步：提取洛谷难度参照（如有）

读题面，检查是否包含洛谷难度信息。常见格式：

```
难度：提高+/省选-
洛谷难度：普及/提高-
难度等级：普及-
```

若找到，记为维度 D 参照值。若未找到，D 维度不参与计算。

### 洛谷难度 → 分值映射

| 洛谷等级 | D 分值 |
|---------|--------|
| 入门 | 1 |
| 普及- | 1.5 |
| 普及/提高- | 2.5 |
| 普及+/提高 | 3.5 |
| 提高+/省选- | 4.5 |
| 省选/NOI- | 5.5 |
| NOI/NOI+/CTSC | 6.5 |

---

## 第二步：四维评分

### 维度 A：知识点深度（1-5 分）

考察题目**核心知识点**的难度层级：

| 分值 | 知识点层级 | 典型知识点 |
|------|-----------|-----------|
| 1 | 纯语法 | if/else、for 循环、一维数组、输入输出 |
| 2 | 进阶语法 | 结构体、字符串处理、嵌套循环、二维数组、自定义函数 |
| 3 | 简单算法 | 素数筛、GCD/LCM、二分查找、排序、简单贪心、进制转换、递归 |
| 4 | 中级算法 | DFS/BFS、基础 DP（背包/线性）、并查集、前缀和与差分、最短路 |
| 5 | 高级算法 | 线段树、树链剖分、网络流、高级数论（原根/欧拉函数）、数位 DP |

### 维度 B：标程算法复杂度（1-5 分）

评估**标程（std.cpp）**的时间复杂度。初评时根据题面数据范围推测，终评时以实际算法为准。

| 分值 | 时间复杂度 | 说明 |
|------|-----------|------|
| 1 | O(n) 或 O(1) | 直接模拟、单遍遍历 |
| 2 | O(n log n) | 排序、二分查找 |
| 3 | O(n√n) 或 O(n·log²n) | 需要一定优化，如筛法、分块 |
| 4 | O(n log n) 但算法复杂 | 线段树操作、树上 DP、图论算法 |
| 5 | 高级算法 | 需要深度数学推导、高级数据结构组合 |

**初评技巧**：看数据范围反推复杂度需求：
- N ≤ 20 → O(n!) 暴力可过，B=1
- N ≤ 1000 → O(n²) 可过，B=2
- N ≤ 10⁵ → O(n log n) 需要，B=2~3
- N ≤ 10⁶ → O(n) 或 O(n log n)，B=3
- N ≤ 10⁷+ → 必须 O(n) 或更优，B=4+

### 维度 C：思维深度（1-5 分）

评估解题所需的**思维转化难度**：

| 分值 | 思维要求 | 说明 |
|------|---------|------|
| 1 | 直接翻译 | 题意即算法，无需转化 |
| 2 | 简单观察 | 需要发现简单规律或贪心策略 |
| 3 | 建模转化 | 需要将问题转化为已知算法模型（如图论/数论） |
| 4 | 综合运用 | 需要组合多个知识点，或转化不显然 |
| 5 | 创造性思维 | 需要复杂证明、创造性构造、深度数学推导 |

### 维度 D：洛谷难度参照

若第一步找到了洛谷难度，按映射表取分值。若未找到，此维度跳过。

---

## 第三步：计算总分

**有洛谷参照时**（四维）：
```
总分 = A×0.25 + B×0.30 + C×0.30 + D×0.15
```

**无洛谷参照时**（三维）：
```
总分 = A×0.30 + B×0.35 + C×0.35
```

## 第四步：映射到难度等级

| 总分范围 | 等级 | 默认分值 |
|---------|------|---------|
| 1.0 - 1.2 | IRON | 10 |
| 1.2 - 2.0 | BRONZE | 20 |
| 2.0 - 2.5 | SILVER | 35 |
| 2.5 - 3.0 | GOLD | 55 |
| 3.0 - 3.5 | PLATINUM | 80 |
| 3.5 - 4.0 | DIAMOND | 110 |

| 4.5 - 5.0 | CHAMPION | 200 |

边界情况：总分恰好等于边界值时，**优先选较高难度**（宁高勿低）。

## 第五步：定标签

- 双指针与滑动窗口
- 前缀和与差分

**数学类：**

- 高精度算法

### 标签选择规则

1. **必含 1~4 个标签**，其中至少 1 个知识点标签
2. **贵精不贵多**：选最核心的 1~3 个知识点标签
3. **难度标签不写入 tags**：difficulty 字段单独存，tags 只放知识点
4. **标签要与难度匹配**：GOLD 题不应只有 SILVER 级别的标签

### ⚠️ 少儿编程防偏规则

1. **iron 和 bronze 的题目**：**必须优先使用"语言入门"类的标签**
2. **不要把普通 for 循环累加题打上 `枚举与暴力` 或 `基础数学` 标签**，直接打 `循环结构`
3. **区分 `递归函数` 与 `深度优先搜索`**：
   - `递归函数`：斐波那契、求阶乘等计算型递归
   - `深度优先搜索`：走迷宫、八皇后等回溯型搜索

## 评分示例

### 示例 1：B3871 因数分解
- A（知识点）：3 分（基础数论 - 分解质因数）
- B（复杂度）：2 分（O(√n) 试除法）
- C（思维）：2 分（直接实现试除法）
- D（洛谷）：普及/提高- ≈ 2.5 分
- 总分 = 3×0.25 + 2×0.30 + 2×0.30 + 2.5×0.15 = 2.425 → **SILVER** ✓

### 示例 2：P11961 原根判断
- A（知识点）：5 分（高级数论 - 原根、欧拉函数、快速幂）
- B（复杂度）：3 分（O(√p · log p) 分解 p-1 + 快速幂验证）
- C（思维）：4 分（需要理解原根的数学定义和判定条件）
- D（洛谷）：提高+/省选- ≈ 4.5 分
- 总分 = 5×0.25 + 3×0.30 + 4×0.30 + 4.5×0.15 = 3.925 → **DIAMOND** ✓

### 示例 3：B3968 成绩排序
- A（知识点）：2 分（结构体 + 排序）
- B（复杂度）：2 分（O(n log n) 排序）
- C（思维）：1 分（直接按题意排序）
- D（洛谷）：普及/提高- ≈ 2.5 分
- 总分 = 2×0.25 + 2×0.30 + 1×0.30 + 2.5×0.15 = 1.775 → **BRONZE**

> 注意：终评时若发现实际标程用了更简单的算法，可能需下调。
