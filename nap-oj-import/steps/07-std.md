## 验证流程（三级验证）

### 第一级：样例验证（必须，不可跳过）

写完 std.cpp **必即**用题面样例验之：

```bash
cd {WORK_DIR}
g++ std.cpp -o std -std=c++17

# 逐样例输入验输出，一一对照题面
echo "【样例输入1】" | ./std
# 核出与题面样例输出1一致否

echo "【样例输入2】" | ./std
# 核出与题面样例输出2一致否

# ... 诸样例逐一验
```

**禁**：
- ❌ 写 std 不验样例即写 mkin.h / 生数据
- ❌ 只验一样例即谓全对
- ❌ 样例未过仍续生数据

**必**：
- ✅ 诸题面样例全过方可入下级验证
- ✅ 样例不过则改 std.cpp，重验，至全过

### 第二级：边界验证（来自风险目录）

自 `{WORK_DIR}/boundary.md` 读取**选定测试边界**（标 ✅ 的风险），逐一构造输入验证：

```bash
# 对每个选定边界风险，构造对应输入并检查 std 输出
# 例：风险 #4 "N=1 退化"
echo "1
5" | ./std
# 检查输出是否合理
```

**原则**：
- 只验 boundary.md 中"当前题是否需测"为 ✅ 的风险
- ❌ 不验的风险 = 当前难度不要求卡，标程正确即可
- 边界验证失败 → 修 std.cpp → 从第一级重验

### 第三级：暴力对拍（可选，SILVER 及以上推荐）

对 SILVER 及以上难度，建议写一个**暴力程序** `{WORK_DIR}/brute.cpp` 做对拍：

```cpp
// brute.cpp：暴力/朴素解法，用于验证 std 的正确性
// 不需要考虑效率，正确即可
```

```bash
g++ brute.cpp -o brute -std=c++17

# 生成小规模随机数据，对拍验证
for i in {1..20}; do
    # 生成小规模输入（N ≤ 20 左右）
    python3 -c "..." > tmp.in
    ./std < tmp.in > tmp_std.out
    ./brute < tmp.in > tmp_brute.out
    diff tmp_std.out tmp_brute.out || echo "MISMATCH on case $i"
done
```

**对拍规则**：
- GOLD+ 难度**强烈建议**对拍
- SILVER 难度视题目复杂度决定
- BRONZE 及以下**不需要**对拍
- 对拍数据只需小规模（验证正确性，非效率）

## 难度终评（标程验证通过后）

### 为什么需要终评

step 3 的初评基于题面推测，可能不准确。标程写完后，可以准确评估：
- 实际使用了什么算法（维度 A）
- 实际时间复杂度是多少（维度 B）
- 解题思维转化难度（维度 C）

### 终评流程

1. **回顾标程**：分析 std.cpp 中实际使用的算法和数据结构
2. **重新评分**：用 step 3 的四维评分标准，重新评估维度 A、B、C
   - 维度 D（洛谷参照）保持不变
3. **计算总分**：用同样的加权公式
4. **确定难度**：查等级映射表
5. **更新 problem.json**：若终评与初评不同，更新 difficulty 和 score

### ⚠️ 终评后更新风险目录

若终评难度与初评不同，**必须回头更新 `boundary.md`**：

- 重新筛选"当前题是否需测"列（终评难度 ≥ 最低难度 → ✅）
- 可能新增或减少选定的测试边界
- 这直接影响后续 `08-testdata.md` 的数据设计

### 终评重点关注

| 情况 | 处理 |
|------|------|
| 终评 = 初评 | 无需修改 |
| 终评比初评高 1 级 | 更新 problem.json + 重新筛选 boundary.md |
| 终评比初评低 1 级 | 更新 problem.json + 重新筛选 boundary.md（可能减少 Hack 数据） |
| 终评与初评差异 > 1 级 | 更新 problem.json + 重新筛选 boundary.md，并检查初评哪一步出错 |

### 终评示例

**B3951 小杨的队列**：
- 初评：A=3, B=2, C=2 → SILVER
- 标程实际算法：对每个查询遍历已入队同学，统计身高 ≥ 新同学的人数，O(N·M)
- 终评：A=2(排序+模拟), B=1(O(N·M) 直接遍历), C=2(需要理解插入排序的位移本质)
- 总分 = 2×0.30 + 1×0.35 + 2×0.35 = 1.65 → **BRONZE**（下调一级）
- boundary.md 影响：原来按 SILVER 筛选的风险，现在需按 BRONZE 重新筛选

**P11961 原根判断**：
- 初评：A=5, B=3, C=4, D=5 → DIAMOND
- 标程实际算法：分解 p-1 的质因子 + 快速幂验证，O(√p · log p)
- 终评：与初评一致，保持 **DIAMOND**

### ⚠️ 终评铁律

- 终评是**最终结果**，不可跳过
- 若终评与初评不同，**必须以终评为准**更新 problem.json
- 终评变化时，**必须更新 boundary.md 并重新筛选风险**
- 标程未通过样例验证时，**不可进行终评**
